# AEROLITH desktop personality

Era inspiration: Longhorn-era experimentation

## Visual direction
Layered depth, translucent-surface visual language, cool blue highlights, and spacious navigation; original design, no copied assets.

## Original sound identity
Airy, glassy bell-like synthesized notes.

This is an ASTRAL design specification. It does not reproduce proprietary Windows artwork, icons, fonts, sounds, or exact interface assets. The style becomes a selectable desktop session only after its implementation and hardware testing are complete.

Sound profile: `ASTRAL-AEROLITH`.
