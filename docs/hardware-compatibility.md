# Hardware compatibility

Compatibility is a goal, not yet a verified guarantee.

| Target class | Goal | Status |
|---|---|---|
| 486 / early Pentium | BIOS boot, text mode, minimal legacy environment | Research |
| Pentium / Pentium MMX | Lightweight classic desktop where feasible | Research |
| Pentium II / III | Classic 32-bit experience | Research |
| Early 2000s x86 PCs | Ubuntu-based live/installable edition when supported | Planned |
| Modern x86-64 PCs | Ubuntu-based edition | Planned |

## Test record

For each tested machine record CPU, RAM, graphics adapter, storage controller, boot method, result, and limitations. Do not mark a device supported based only on a successful virtual-machine boot.
