# ASTRAL Linux

**A classic-computing Linux distribution by AtDev, based on Ubuntu.**

ASTRAL brings a lightweight, familiar desktop experience to vintage and low-resource PCs, while keeping a practical Ubuntu-based edition for compatible hardware.

## Desktop personalities

ASTRAL will offer five original interface personalities:

- **DOSERA** — compact, group-based application desktop.
- **PIXEL** — classic taskbar and desktop workflow.
- **MOSAIC** — panel-oriented workspace and visual file navigation.
- **FORGE** — restrained, productivity-focused desktop.
- **NOVA** — colorful multimedia-era desktop.

These are original ASTRAL designs inspired by classic computing eras, not copies of proprietary operating-system assets.

## Editions

- **Classic** — Ubuntu-based edition for hardware supported by its Ubuntu base.
- **Legacy** — experimental 32-bit/BIOS-oriented research for older PCs. Compatibility depends on available kernels, drivers, and package support.
- **Modern** — optional edition for newer compatible PCs.

## Hardware goals

ASTRAL is designed with BIOS-era computers, VGA graphics, IDE storage, and limited memory in mind. The project will document tested hardware rather than claim universal compatibility.

Ubuntu's current releases do not provide a complete modern i386 installation stack. The Legacy edition therefore requires a separately validated legacy base and must not be represented as a current Ubuntu i386 release.

## Project status

Early development. No installable ISO is published yet.

## First milestone

Build a reproducible Ubuntu-based live image with the PIXEL personality, AtDev branding, and a basic installer path. Legacy hardware support will be developed and tested separately.
