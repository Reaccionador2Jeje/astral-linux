CHOOSE YOUR EXPERIENCE

Una familia. Tres caminos.

Las ediciones definen el objetivo de compatibilidad. Los estilos definen la personalidad visual del escritorio.

01 / CLASSIC

ASTRAL Classic

Escritorio tradicional y recursos contenidos.

La edición de referencia para PCs clásicos y equipos modestos. PIXEL es el primer escritorio que estamos preparando para la imagen Live.

02 / MODERN

ASTRAL Modern

Experiencia visual contemporánea.

Agrupa las personalidades modernas de ASTRAL. Cada perfil tendrá integración y su propia ISO cuando esté lista.

03 / LEGACY

ASTRAL Legacy

Compatibilidad con hardware antiguo.

Objetivo para equipos de generaciones anteriores. Requiere compilación y arquitectura compatibles; todavía no hay ISO publicada.

Configura arranque BIOS y conecta el archivo ISO como unidad CD-ROM IDE.

03 / RESOURCES

Recursos virtuales

Como punto de partida: 2 núcleos y 2 GB de RAM. Ajusta si el emulador lo necesita.

Para probar instalación, utiliza únicamente un disco virtual vacío y desechable. Nunca selecciones un disco con archivos personales. La compatibilidad debe confirmarse con pruebas.
GOOD TO KNOW

Preguntas frecuentes.

¿Ya están disponibles las 11 ISO?

No. Los 11 estilos están en el catálogo de diseño. Cada ISO aparecerá como disponible solo cuando exista un archivo publicado.

¿Qué significa Classic, Modern y Legacy?

Son las tres líneas de edición planeadas. Legacy requerirá una imagen y estrategia de compatibilidad separadas para hardware antiguo.

¿Puedo instalar cualquier estilo?

La disponibilidad depende de cada compilación. PIXEL es el primer escritorio con integración de sistema; los otros estilos necesitan implementación y pruebas propias.

¿Cómo se publican las descargas?

El catálogo consulta las versiones públicas del repositorio oficial de ASTRAL Linux y presenta sus archivos adjuntos.
